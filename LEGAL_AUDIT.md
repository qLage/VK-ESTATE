# LEGAL_AUDIT — первичный аудит vkrysha.ru

Дата: 2026-10-06.  
Стек: Vite + React SPA, nginx, leads-api (Node), CRM `vkrysha-crm.ru`.

## Карта потоков ПДн

```mermaid
flowchart TD
  user[User] --> contactForm[ContactForm]
  user --> referralForm[ReferralModal]
  user --> maps[Yandex_Maps_iframe]
  user --> social[Social_links_external]
```
